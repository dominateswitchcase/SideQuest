Create a professional, mobile-first prototype for a location discovery application called **Sidequest**.

You are acting as a **senior product designer and senior software engineer**. Build a polished, presentation-ready prototype quickly. The goal is to demonstrate the core product experience within a few minutes, not to create a production-ready application.

The prototype must feel like it was designed by a professional product team. It must NOT look "vibe coded," AI-generated, overly decorative, or like a generic startup template.

Prioritize:
1. Clear user flow
2. Strong information hierarchy
3. Professional mobile UI

5. Functional clickable prototype

# 1. PRODUCT CONCEPT

**Sidequest** is a location discovery application that helps users decide where to go next.

Users can discover:

- Food
- Cafes
- Adventures
- Scenic locations
- Tourist attractions
- Activities

The application recommends places based on:

- User location
- Category
- Budget
- Distance
- Opening status
- Interests

The primary problem Sidequest solves is:

**"I don't know where to go."**

Instead of requiring users to search through many places, Sidequest provides relevant recommendations that users can immediately visit.

The target users are primarily students, young adults, and people who enjoy discovering new places.
